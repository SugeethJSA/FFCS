# FFCS Desktop (Tauri 2)

Bundles `FFCS` static `out/` + `ffcs-extension` into a 8-15 MB installer. Fellow admins install once → auto-updates.

## Dev (iterate very quickly)

```bash
# terminal 1: backend + frontend
pnpm --filter ffcs-backend dev    # :4000
pnpm --filter ffcs dev            # :3004

# terminal 2: desktop (loads http://localhost:3004)
pnpm --filter ffcs-desktop dev
# edit FFCS/src/app/admin/attendance/* → HMR <1s in desktop window
```

## Build installers

```bash
pnpm --filter ffcs build          # creates FFCS/out
pnpm --filter ffcs-desktop build  # creates src-tauri/target/release/bundle/{msi,dmg,appimage}
```

Artifacts: `src-tauri/target/release/bundle/msi/FFCS Track_1.0.0_x64_en-US.msi`, `dmg/FFCS Track_1.0.0_x64.dmg`

## Extension inside desktop

`tauri.conf.json:bundle.resources: ["../ffcs-extension/*"]` ships the MV3 extension. At runtime `save.js` syncs `ffcs_access` via `chrome.storage` if running in Chrome, or via `localStorage` bridge when running inside Tauri webview (injected via `initializationScript`).

For now desktop just wraps the web UI — Meet capture still via installed Chrome extension. Phase: inject `ffcs-extension/attendance.js` into Tauri webview for native capture (add `tauri` `webview` `initialization_script` in `src-tauri/src/main.rs`).

## Auto-update

`tauri-plugin-updater` checks `https://ffcs.club/releases/latest.json` (generated by CI). Bump `package.json` + `tauri.conf.json` `version`, `git tag v1.0.1` → CI builds and updates `latest.json`.

## Fallback (no Rust)

If Rust blocked: `node ffcs-extension/scripts/launch-chrome.js` (`chrome-launcher --load-extension`) packaged via `pkg` → `FFCS-Track-Launcher.exe`.

## Icons

Reused `ffcs-extension/icons/ffcs-logo-*.png` → `src-tauri/icons/`.
