# 04 — Desktop & Browser Packaging: Install Once, Iterate Fast

## Goal

Fellow admins install **once** and get: FFCS web + Meet tracker, auto-updates, no `Load unpacked` dance. Meanwhile devs iterate `pnpm dev` with HMR in <2s.

---

## 1. Options evaluated

| Option | What it is | Pros | Cons | Verdict |
|---|---|---|---|---|
| **A. Standalone extension (Chrome Web Store)** | Publish `ffcs-extension` to Chrome Web Store + Edge Add-ons | Familiar, auto-update, smallest bundle | Review delay (days), needs $5 dev fee, Firefox separate, no desktop offline | **Ship as part of B, but also publish** |
| **B. Tauri 2 desktop wrapper** | Rust-based desktop app wrapping `FFCS/out` + sidecar extension host | 5–15 MB installer (vs Electron 150 MB), native auto-updater (`tauri-plugin-updater`), `wxt` HMR still works, one `pnpm tauri dev` | Requires Rust toolchain, slightly more setup | **Recommended primary** — fits "very very quickly" iterate + tiny installer |
| **C. Electron** | Chromium wrapper | Easiest to bundle extension via `electron/extensions`, full Node access | 120+ MB, slower CI, higher memory | Fallback if Tauri webview quirks on VIT lab machines |
| **D. PWA only** | `next-pwa` installable web app | Zero install friction, works on mobile | **Cannot** access `meet.google.com` DOM → no auto Meet capture | Not sufficient alone |

**Choice: B + A.** Ship **Tauri desktop** that embeds the same `wxt`-built extension logic as a sidecar `Chrome Extension` (via `tauri-plugin-single-instance` + deep link `ffcs://attendance/...`). Also publish extension to store for non-desktop users.

## 2. Extension architecture (fork of Trackit)

**Source:** `trackit/apps/browser-extension/` (46 lines `manifest.json:43` MV3, 146 lines `attendance.js`, `save.js`, `background.js`).

**New location:** `FFCS/ffcs-extension/` built with **WXT** (`wxt.dev`, Vite-based, HMR for MV3):

```
ffcs-extension/
  wxt.config.ts         # target chrome/firefox, define manifest
  src/
    entrypoints/
      background.ts     # was background.js: open FFCS dashboard on install, token sync
      attendance.content.ts # was attendance.js: 1s poll, parseRegNo, queue
      save.content.ts       # was save.js: bridge chrome.storage → API
    utils/
      parseRegNo.ts     # shared ../FFCS-backend/src/utils/parseRegNo.ts
      api.ts            # POST /api/attendance/meet with JWT
    assets/icons/       # reuse trackit/icons/mac-logo-*.png rebrand to FFCS
  package.json
```

**Key changes from Trackit:**

1. **Retarget domain:** `manifest.json:22 save.js matches ["https://trackit.visualbrahma.tech/*"]` → `["${FFCS_FRONTEND_URL}/*"]` (env-driven, default `http://localhost:3004` dev, prod `https://ffcs.club`).
2. **Selector robustness:** Trackit's `.m3Uzve.RJRKn [role="listitem"]` breaks when Google changes classes. Add fallback selector array + versioned config fetch `GET /api/extension/config` returning `selectors: string[]` (admin can hotfix without extension update).
3. **Auth:** Instead of `chrome.storage.local → localStorage` bridge, extension reads `ffcs_access` JWT from `chrome.storage.local` (synced by `FFCS/src/lib/api.ts` `setTokens` also writing to `chrome.storage` if `chrome.storage` exists). If no token, queue uploads and show `🔴 FFCS — login required` red blink (reuse `attendance.js:118 statusText`).
4. **Offline queue:** `chrome.storage.local` key `ffcs_meet_queue: [{uuid, details, attempts}]` retry on `navigator.onLine` or next `stop()`.
5. **Build:** `pnpm wxt dev` → HMR, `pnpm wxt zip` → `ffcs-extension.zip` for store, `pnpm wxt build` → `dist/` consumed by Tauri.

## 3. Tauri desktop — "very very quickly" iterate

**Location:** `FFCS/ffcs-desktop/` (`tauri@2`)

```toml
# ffcs-desktop/src-tauri/Cargo.toml
[package] name="ffcs-desktop" version="1.0.0"
[dependencies] tauri = "2", tauri-plugin-updater = "2", tauri-plugin-shell = "2"
```

```json
// ffcs-desktop/src-tauri/tauri.conf.json
{
  "productName": "FFCS Track",
  "identifier": "club.ffcs.track",
  "build": { "beforeDevCommand": "pnpm dev", "beforeBuildCommand": "pnpm build && pnpm --filter ffcs-extension build" },
  "app": { "windows": [{ "url": "http://localhost:3004", "label": "ffcs" }], "security": { "csp": null } },
  "bundle": { "active": true, "targets": ["msi","nsis","dmg","appimage"], "icon": ["icons/icon.png"] },
  "plugins": { "updater": { "pubkey": "...", "endpoints": ["https://ffcs.club/releases/latest.json"] } }
}
```

**Flow for admins:**
1. Download `FFCS-Track-1.0.0.msi` (Windows lab) / `dmg` (Mac) from `ffcs.club/download` or GitHub Releases.
2. Install → app opens `FFCS` leaderboard + menubar tray `FFCS Track` with `Start Meet Capture` toggle (calls same `attendance.js` injected via `tauri` `webview` `window.__TAURI__`).
3. Auto-update: `tauri-plugin-updater` checks `https://ffcs.club/releases/latest.json` on launch (generated by `tauri github-action` on tag push).

**Dev iterate:**
```bash
pnpm dev            # FFCS + backend + extension watch (wxt HMR)
pnpm --filter ffcs-desktop tauri dev  # opens desktop window with live reload
# Edit FFCS/src/app/admin/attendance/page.tsx → saves → desktop refreshes <1s
```

Single `pnpm dev` script in root `pnpm-workspace.yaml` orchestrates all 3.

**Why Tauri fits "install once, iterate quickly":**
- **Size:** ~8 MB vs Electron 150 MB → lab machines with slow internet succeed.
- **Reuse:** `FFCS/out` static build is loaded directly as Tauri frontend — no duplicate UI code.
- **Extension bundling:** `ffcs-desktop/src-tauri/src/lib.rs` registers the `ffcs-extension` content scripts via `webview` injection at startup, so desktop capture works even if user never installed store extension.
- **Signing:** `tauri signer generate` → CI signs `msi/dmg`, admins don't see "Unknown publisher".

## 4. Alternative path if Tauri blocked

If Rust toolchain blocked on admin laptops, fallback **WXT + `chrome-launcher` script**:

```bash
# ffcs-extension/scripts/launch-chrome.js
import { launch } from 'chrome-launcher'
launch({ startingUrl: 'http://localhost:3004', args: ['--load-extension=./dist'] })
```

Packaged as `pkg` Node binary → `FFCS-Track-Launcher.exe` (no Rust). Same UX, slightly larger than Tauri but still <30 MB.
